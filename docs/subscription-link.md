# Subscription Import Link

The `husi://subscription?…` scheme imports a proxy group into husi. Two forms are accepted.

## Cleartext form

```
husi://subscription?url=<encoded-url>[&name=<name>][&type=<format>]
```

| Parameter | Required | Description                                                    |
|-----------|----------|----------------------------------------------------------------|
| `url`     | yes      | Percent-encoded URL of the subscription feed                   |
| `name`    | no       | Display name; falls back to the URL fragment (`#…`) if omitted |
| `type`    | no       | Feed format: `raw` (default), `oocv1`, or `sip008`             |

Example:

```
husi://subscription?url=https%3A%2F%2Fexample.com%2Fsub&name=My+Sub&type=raw
```

## Opaque form

```
husi://subscription?<payload>
```

**This is internal link, without no-breaking-change promise and cross version compatibility, do not
rely on it.**

`<payload>` is URL-safe Base64 of a zlib-compressed, Kryo-serialized `ProxyGroup` in export mode.
This form is generated by the app's "share group" feature. It carries the group name, type, and
subscription settings (no internal database IDs).

## sing-box compatibility

```
sing-box://import-remote-profile?url=urlEncodedURL#urlEncodedName
```

See <https://sing-box.sagernet.org/clients/general/#remote>
